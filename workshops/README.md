# KCL Tech Academy: four workshop versions

Four cumulative, independent Java 21 + JavaFX projects build towards the same 2D Minecraft-inspired sandbox. Each is a working reference for the **end** of a two-hour workshop, with its own Maven build, bundled assets, tests and instructions. Later systems are introduced in the corresponding version's source.

| Workshop | Open this project | Result |
| --- | --- | --- |
| 1 | [workshop-01](workshop-01/README.md) | Tile world, JavaFX game loop and horizontal movement |
| 2 | [workshop-02](workshop-02/README.md) | Gravity, jumping, collision, mining and placing dirt |
| 3 | [workshop-03](workshop-03/README.md) | Resource counters, material-specific placement, one sword recipe and one enemy type |
| 4 | [workshop-04](workshop-04/README.md) | Combat, enemy defeat and the final playable game |

## Teaching the progression

Open just the chosen workshop folder in IntelliJ as a Maven project and select JDK 21. Run **Plugins → javafx → javafx:run** in the Maven tool window. Students continue developing their own code; use the checkpoint if a student needs a working recovery point. Keep independent work between sessions focused on the session's concepts.

Workshop 1 uses level terrain and horizontal movement. Workshop 2 introduces physics and an editable map; right click places unlimited dirt. Workshop 3 makes block identity and supply matter: mining collects dirt, stone or wood and placement spends the selected resource. It also adds a sword recipe and patrolling enemies. Workshop 4 connects the crafted sword to combat, damage and defeat. Its first 90 minutes are for building, testing and fixes; the **last 30 minutes are student presentations**.

There is one crafting recipe and one enemy type, with several instances of that type. Resource counters stay visible in the HUD. Procedural terrain, extra recipes, a full inventory interface, advanced AI, multiplayer and save/load are optional extensions.

## Build, run and distribute

From the repository root:

```sh
# Compile and test all four projects.
mvn --file workshops/pom.xml verify

# Launch one version (replace 02 with 01, 03 or 04).
mvn --file workshops/workshop-02/pom.xml javafx:run
```

The aggregator `pom.xml` is only for building/testing. Run JavaFX against an individual workshop project. Each project also works outside this repository: copy its folder, or use the ZIP files generated by `scripts/package-workshops.ps1` at the repository root. JavaFX and JUnit dependencies are downloaded by Maven on first use.
