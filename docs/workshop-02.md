# Workshop 2: Physics, collision and world interaction (2 hours)

## Topics
- Vertical velocity, gravity and jump impulses
- Axis-aligned rectangle/tile collisions
- Mapping mouse clicks from screen space to world-space tiles
- Changing world tiles at runtime

## Build in class
1. Add gravity and grounded jump behaviour to Player.
2. Stop the player passing through solid tiles using the World collision method.
3. Left click: remove a block in reach.
4. Right click: place a block in an empty tile in reach.
5. Prevent placing blocks on the player.

## Checkpoint
A character jumps, lands and can mine/place terrain without walking through solid blocks.

## Reference files
`Player.java`, `World.java`, `Collision.java`, plus the mouse handler in `SandboxGame.java`.

## Independent work
Review block interactions and test the boundaries of the world.
