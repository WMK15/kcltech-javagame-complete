# Workshop 1: IntelliJ IDEA, world and movement (2 hours)

## Topics
- Transition from the previous editor to IntelliJ IDEA
- JDK 21, Maven project import and running JavaFX in IntelliJ
- Stage, Scene, Canvas, GraphicsContext
- AnimationTimer game loop and frame delta time
- Tile grids, classes/objects and keyboard input

## Build in class
1. Open a Maven JavaFX project in IntelliJ and confirm a blank window opens.
2. Draw a sky and rectangular ground tiles on Canvas.
3. Represent the world as a two-dimensional tile array.
4. Add a Player class with position and width/height.
5. Update left/right movement through the game loop.

## Checkpoint
A JavaFX window displays a 2D world and a player who moves horizontally.

## Reference files
`GameConfig.java`, `World.java`, `Player.java`, and `SandboxGame.java` (only the rendering, loop and horizontal input sections).

## Independent work
Review tile coordinates, player state, and the update/render distinction ahead of physics.
